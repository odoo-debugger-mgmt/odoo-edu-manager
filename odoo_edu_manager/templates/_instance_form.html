Addons
One absolute path per line. Each is mounted separately and added to the container's addons-path. Leave blank for none. Each directory's immediate children must be actual Odoo modules (containing __init__.py + a manifest) — Odoo rejects a path otherwise, so point at the specific module folder, not a parent folder of unrelated project subfolders.
Enterprise
Off by default: a new instance is Community. Ticking it clones odoo/enterprise (branch matching the selected version) over SSH the first time it's needed for that version, then reuses the cached clone for later instances — which needs a GitHub SSH key with access to that private repo, or a local Enterprise folder below.
Use a local Odoo Enterprise checkout instead of cloning from GitHub — for when you don't have SSH access to the private repo. If the folder you pick is a git repo you can choose a branch, and that branch gets copied out and used (same as for addons folders above), leaving your working copy untouched. Mounted read-only. Only used when "Include Odoo Enterprise" is ticked.
