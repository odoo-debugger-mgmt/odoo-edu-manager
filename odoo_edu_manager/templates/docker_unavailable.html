Docker isn't reachable

Every Odoo instance runs as a Docker container, and this app can't talk to Docker right now. Nothing is lost: your instances and their data are still there, and this page goes away as soon as Docker answers.

What to do

{% if permission %}

Docker is running, but your user isn't allowed to use it yet:

sudo usermod -aG docker $USER

Then close the terminal and open a new one (inside WSL, run wsl --shutdown from Windows first), start the app again, and reload this page.

{% elif platform == "wsl" %}

Docker isn't running in this Linux (WSL). Start it:

sudo service docker start

then reload this page. If you use Docker Desktop instead, start it and make sure Settings → Resources → WSL integration is switched on for this distribution.

{% elif platform == "desktop" %}

Start Docker Desktop, wait until it says it is running, then reload this page.

{% else %}

Docker isn't running. Start it:

sudo systemctl start docker

then reload this page. If docker isn't installed at all, install Docker Engine first (see the README).
